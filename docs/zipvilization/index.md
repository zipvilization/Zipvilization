# 🌍 Zipvilization

**Zipvilization is a readable civilization built on public on-chain data.**

It is not a game.  
It is not a financial dashboard.  
It is not a simulation with hidden rules.

Zipvilization exists to make an on-chain system **visible, explorable, and understandable** as territory, history, and structure.

---

## 🧭 What You See in Zipvilization

When you enter Zipvilization, you interact with:

- 🌱 **Territory** — land measured in square meters
- 👤 **Colonists** — wallets represented as inhabitants
- 🗺️ **World views** — maps at different levels of scale
- ⏳ **History** — how the world has evolved from genesis to now
- 🔍 **Observation tools** — inspect any visible territory or wallet

Everything you see is derived from **public blockchain data**.

Nothing is hidden. Nothing is invented.

---

## 🧩 How Zipvilization Is Built

Zipvilization is composed of several technical layers.

Each layer has a **clear responsibility**, and each one is reflected in what you see.

| Technical Layer | Responsibility | User Experience |
|-----------------|----------------|-----------------|
| **[Solum](../solum/)** | On-chain substrate | Territory size, limits and permanence |
| **[SolumTools](../solumtools/)** | Data interpretation | Metrics, roles and visibility |
| **[SolumWorld](../solumworld/)** | Canonical world model | Maps, zoom levels, states and evolution |
| **SolumView** | Visual expression | Interface, timelines and Wallet Mode |

This documentation does not redefine those systems.

It explains **how they manifest to the user**.

---

## 👁️ Transparency by Design

Zipvilization is fully observable.

- Any wallet can be inspected.
- Any territory can be explored.
- Any historical state can be reviewed.
- Any visible metric can be traced back to its on-chain origin.

There are:

- ❌ No private dashboards
- ❌ No hidden modifiers
- ❌ No narrative filters

What you see is what exists.

---

## 🚫 What Zipvilization Is Not

Zipvilization does **not**:

- Provide financial advice
- Recommend actions
- Predict prices or outcomes
- Judge behavior as good or bad
- Gamify participation

Zipvilization observes.

Meaning emerges from structure and time.
