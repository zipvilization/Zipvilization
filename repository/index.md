# Repository

The Atlas has one purpose.

**To help Humans and Artificial Intelligence understand Zipvilization.**

The Repository has another.

**To document, verify and preserve Zipvilization.**

Every specification.

Every architectural decision.

Every implementation.

Every important evolution of the project is recorded in the official GitHub Repository.

The website explains.

The Repository proves.

---

# Why GitHub?

Knowledge should remain:

- Public
- Versioned
- Auditable
- Verifiable

The Repository is not an appendix to Zipvilization.

It is one of its foundations.

If a concept is not documented or implemented in the Repository, it should not yet be considered part of the canonical project.
