# Repository

Welcome to the official **Zipvilization Repository**.

This Repository is the canonical source of the project.

It contains the technical documentation, conceptual architecture, source code and implementation history that define Zipvilization.

If something is not documented or implemented here, it should not yet be considered part of the canonical project.

---

# Repository Philosophy

The Repository exists to make Zipvilization:

- Public
- Transparent
- Versioned
- Auditable
- Verifiable

The public website introduces the project.

This Repository preserves its knowledge.
