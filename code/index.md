The Code section documents the technical implementation of **[Zipvilization]({% link docs/zipvilization/index.md %})**.

While the canonical documentation defines the concepts, rules and architecture of the project, the Code section explains how those concepts are implemented in practice.

| Document | Purpose |

- **[Solum]({% link docs/solum/index.md %})** defines the immutable contract.
